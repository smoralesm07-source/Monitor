NOTA SOBRE entidades.html
-------------------------
La v3 solo AGREGA campos a la salida; no elimina ni renombra ninguno de los
que consume la interfaz actual. entidades.html sigue funcionando sin cambios.
Los campos nuevos (naturaleza, confianza_score, senales, ruts) quedan
disponibles en datos.json para cuando quieras exponerlos en la página.

DEPENDENCIA NUEVA
-----------------
rapidfuzz>=3.0  — resuelve correferencias y variantes ortográficas.
Si no está instalada, el módulo degrada a comparación exacta y continúa.

EJECUCIÓN LOCAL
---------------
pip install -r requirements_entidades.txt
python -m spacy download es_core_news_sm
python modulo_entidades.py --entrada datos.json --salida datos.json

VALIDACIÓN
----------
python -m unittest test_modulo_entidades test_reconocedor_entidades
python benchmark_entidades.py --salida datos.json

reconocedor_entidades.py no quedó en la raíz. El proceso NO falla: continúa
con el reconocimiento heredado v2, pero sin la clasificación por naturaleza.

PRIMER PASO RECOMENDADO EN PRODUCCIÓN
--------------------------------------
Ejecuta sobre datos.json real y revisa las entidades con
requiere_validacion=true. Ese subconjunto concentra los casos dudosos y es
el mejor punto de partida para anotar una muestra propia y medir el
desempeño real con benchmark_entidades.py.
